Requisitos del sistema

Dashboard de Nómina NetPlus

Requisitos funcionales

  • RF-001 - Autenticación de Usuario: CUANDO el usuario ingrese credenciales válidas, EL SISTEMA DEBE otorgar acceso al panel principal en menos de 2 segundos. Must Have (Obligatorio)
  • RF-002 - Control de Acceso por Rol: CUANDO un usuario autenticado acceda al sistema, EL SISTEMA DEBE mostrar únicamente las opciones permitidas para su rol (Talento Humano, Contabilidad o Gerencia). Must Have (Obligatorio)
  • RF-003 - Configuración de Conexión: EL SISTEMA DEBE permitir configurar los datos de conexión a Z-BioTime (servidor y credenciales). Won't Have (Postergado)
  • RF-004 - Sincronización de Marcaciones: CUANDO el usuario de Talento Humano solicite actualizar los datos, EL SISTEMA DEBE obtener las marcaciones desde Z-BioTime para el rango de fechas seleccionado. Won't Have (Postergado)
  • RF-005 - Sincronización Programada: MIENTRAS el sistema esté en ejecución, EL SISTEMA DEBE sincronizar las marcaciones nuevas diariamente a una hora configurada. Won't Have (Postergado)
  • RF-006 - Manejo de Fallos de Importación: CUANDO la importación del archivo falle, EL SISTEMA DEBE mostrar un mensaje de error y conservar los últimos datos importados. Must Have (Obligatorio)
  • RF-007 - Carga de Marcaciones desde Excel: EL SISTEMA DEBE permitir cargar el archivo Excel de marcaciones exportado de Z-BioTime. Must Have (Obligatorio)
  • RF-008 - Cálculo de Jornada: EL SISTEMA DEBE calcular por empleado y por día la hora de entrada, la hora de salida y las horas trabajadas. Must Have (Obligatorio)
  • RF-009 - Control de Puntualidad: CUANDO la hora de entrada supere el horario establecido más la tolerancia, EL SISTEMA DEBE clasificar el registro como atraso. Must Have (Obligatorio)
  • RF-010 - Control de Asistencia: CUANDO un empleado no tenga marcaciones en un día laborable, EL SISTEMA DEBE registrarlo como falta. Must Have (Obligatorio)
  • RF-011 - Reporte Diario: CUANDO el usuario seleccione una fecha, EL SISTEMA DEBE mostrar el reporte diario de asistencia y puntualidad. Must Have (Obligatorio)
  • RF-012 - Reporte Mensual: CUANDO el usuario seleccione un mes, EL SISTEMA DEBE mostrar el consolidado mensual por empleado (atrasos, faltas y horas trabajadas). Must Have (Obligatorio)
  • RF-013 - Dashboard de Indicadores: EL SISTEMA DEBE presentar indicadores de asistencia y puntualidad en un dashboard con gráficos. Should Have (Deseable)
  • RF-014 - Exportación de Reportes: CUANDO el usuario solicite exportar un reporte, EL SISTEMA DEBE generar un archivo Excel descargable. Could Have (Opcional)
  • RF-015 - Gestión de Usuarios: CUANDO el administrador registre o desactive un usuario, EL SISTEMA DEBE asignarle un rol y actualizar su acceso de inmediato. Must Have (Obligatorio)
  • RF-016 - Configuración de Horarios: EL SISTEMA DEBE permitir definir el horario laboral y la tolerancia de atraso por empleado o grupo. Must Have (Obligatorio)
  • RF-017 - Calendario de Feriados: EL SISTEMA DEBE permitir registrar feriados y días no laborables. Should Have (Deseable)
  • RF-018 - Permisos y Justificaciones: CUANDO Talento Humano registre un permiso o justificación para un empleado, EL SISTEMA DEBE excluir ese día del conteo de faltas y atrasos. Should Have (Deseable)
  • RF-019 - Cálculo de Horas Extra: CUANDO las horas trabajadas en un día superen la jornada establecida, EL SISTEMA DEBE registrar el excedente como horas extra. Should Have (Deseable)
  • RF-020 - Marcaciones Incompletas: CUANDO un empleado tenga una sola marcación en el día, EL SISTEMA DEBE marcar el registro como incompleto y señalarlo a Talento Humano. Must Have (Obligatorio)
  • RF-021 - Depuración de Duplicados: CUANDO existan marcaciones del mismo empleado con menos de 1 minuto de diferencia, EL SISTEMA DEBE considerarlas una sola. Should Have (Deseable)
  • RF-022 - Filtros de Reporte: CUANDO el usuario aplique filtros por empleado, departamento o rango de fechas, EL SISTEMA DEBE actualizar el reporte con los resultados. Should Have (Deseable)
  • RF-023 - Detalle de Marcaciones: CUANDO el usuario seleccione un empleado, EL SISTEMA DEBE mostrar todas sus marcaciones con fecha y hora. Must Have (Obligatorio)
  • RF-024 - Bitácora de Importaciones: CUANDO finalice una importación, EL SISTEMA DEBE registrar fecha, usuario, resultado y cantidad de marcaciones importadas. Should Have (Deseable)
  • RF-025 - Cierre de Sesión: MIENTRAS el usuario tenga una sesión activa, CUANDO permanezca inactivo 15 minutos, EL SISTEMA DEBE cerrar la sesión automáticamente. Should Have (Deseable)

Requisitos no funcionales

  • RNF-001 - Confidencialidad de Datos: EL SISTEMA DEBE almacenar las contraseñas de los usuarios cifradas (hash) y permitir el acceso a la información de nómina solo a usuarios autenticados. Must Have (Obligatorio)
  • RNF-002 - Procesamiento de Marcaciones: EL SISTEMA DEBE procesar 10 000 marcaciones en menos de 10 segundos. Should Have (Deseable)
  • RNF-003 - Facilidad de Uso: EL SISTEMA DEBE permitir al usuario generar un reporte en máximo 3 clics. Should Have (Deseable)
  • RNF-004 - Comunicación Segura: EL SISTEMA DEBE transmitir los datos entre el navegador y el servidor mediante HTTPS. Must Have (Obligatorio)
  • RNF-005 - Bloqueo por Intentos Fallidos: CUANDO un usuario falle 5 veces seguidas al iniciar sesión, EL SISTEMA DEBE bloquear su acceso durante 15 minutos. Should Have (Deseable)
  • RNF-006 - Respaldo de Información: EL SISTEMA DEBE realizar un respaldo diario de su base de datos. Should Have (Deseable)
  • RNF-007 - Disponibilidad: MIENTRAS sea horario laboral, EL SISTEMA DEBE estar disponible al menos el 99% del tiempo. Should Have (Deseable)
  • RNF-008 - Compatibilidad y Diseño Adaptable: EL SISTEMA DEBE funcionar en las últimas versiones de Chrome, Edge y Firefox y adaptarse a pantallas de escritorio y tablet. Should Have (Deseable)

Restricciones

  • REST-001 - Fuente de Datos: EL SISTEMA DEBE obtener las marcaciones únicamente del reporte de marcaciones exportado desde Z-BioTime (v8.0.8). Must Have (Obligatorio)
  • REST-002 - Plataforma: EL SISTEMA DEBE desarrollarse como una aplicación web accesible desde navegador. Must Have (Obligatorio)
  • REST-003 - Integridad de Marcaciones: EL SISTEMA DEBE acceder a las marcaciones de Z-BioTime en modo solo lectura, sin modificarlas. Must Have (Obligatorio)
