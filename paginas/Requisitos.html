Requisitos del sistema

Dashboard de Nómina NetPlus

Inicio Requisitos Tecnologías Figma

Requisitos funcionales

  • RF-001 - Autenticación de Usuario: CUANDO el usuario ingrese credenciales válidas, EL SISTEMA DEBE otorgar acceso al panel principal en menos de 2 segundos. Must Have (Obligatorio)
  • RF-002 - Control de Acceso por Rol: CUANDO un usuario autenticado acceda al sistema, EL SISTEMA DEBE mostrar únicamente las opciones permitidas para su rol (Recursos Humanos / Desarrollo Organizacional o Contabilidad). Must Have (Obligatorio)
  • RF-003 - Almacenamiento de Marcaciones: EL SISTEMA DEBE almacenar en la base de datos PostgreSQL las marcaciones importadas desde el archivo Excel. Must Have (Obligatorio)
  • RF-004 - Validación del Archivo de Marcaciones: CUANDO el usuario cargue un archivo de marcaciones, EL SISTEMA DEBE validar que contenga las columnas esperadas del reporte de Z-BioTime antes de importarlo. Must Have (Obligatorio)
  • RF-005 - Actualización del Dashboard: CUANDO finalice una importación, EL SISTEMA DEBE actualizar el dashboard y los reportes con los datos almacenados en la base de datos. Must Have (Obligatorio)
  • RF-006 - Manejo de Fallos de Importación: CUANDO la importación del archivo falle, EL SISTEMA DEBE mostrar un mensaje de error y conservar los últimos datos importados. Must Have (Obligatorio)
  • RF-007 - Carga de Marcaciones desde Excel: EL SISTEMA DEBE permitir cargar el Excel de marcaciones exportado de Z-BioTime, tanto con todos los empleados en una sola hoja como con una hoja por empleado. Must Have (Obligatorio)
  • RF-008 - Cálculo de Jornada: EL SISTEMA DEBE calcular por empleado y por día la hora de entrada, la hora de salida y las horas trabajadas. Must Have (Obligatorio)
  • RF-009 - Control de Puntualidad: CUANDO la hora de entrada del empleado sea posterior a la hora de entrada de su turno, EL SISTEMA DEBE clasificar el registro como atraso. Must Have (Obligatorio)
  • RF-010 - Control de Asistencia: CUANDO un empleado no tenga marcaciones en un día laborable y no tenga permiso, vacaciones ni feriado aprobado, EL SISTEMA DEBE registrarlo como falta. Must Have (Obligatorio)
  • RF-011 - Reporte Diario: CUANDO el usuario seleccione una fecha, EL SISTEMA DEBE mostrar el reporte diario de asistencia con los empleados ausentes, con atraso, con horas extra y en vacaciones. Must Have (Obligatorio)
  • RF-012 - Reporte por Período de Corte: CUANDO el usuario seleccione un período de corte (del día 21 de un mes al día 20 del siguiente), EL SISTEMA DEBE mostrar el consolidado por empleado con atrasos, faltas, horas trabajadas, horas extra aprobadas y ausencias aprobadas. Must Have (Obligatorio)
  • RF-013 - Dashboard de Indicadores: EL SISTEMA DEBE presentar en un dashboard con gráficos los indicadores de asistencia, puntualidad, horas extra y ausentismo. Must Have (Obligatorio)
  • RF-014 - Exportación de Reportes: CUANDO el usuario solicite exportar un reporte, EL SISTEMA DEBE generar un archivo Excel descargable. Should Have (Deseable)
  • RF-015 - Horario del Turno: EL SISTEMA DEBE contar con el horario del turno de cada empleado (fijo, rotativo o temporal) para calcular atrasos y faltas. Must Have (Obligatorio)
  • RF-016 - Calendario de Feriados: EL SISTEMA DEBE permitir registrar feriados y días no laborables. Should Have (Deseable)
  • RF-017 - Permisos y Justificaciones: CUANDO se importe el reporte de permisos y ausencias, EL SISTEMA DEBE excluir del conteo de faltas y atrasos únicamente las solicitudes en estado Aprobado, sin considerar las Pendientes ni las Rechazadas. Must Have (Obligatorio)
  • RF-018 - Cálculo de Horas Extra: CUANDO se importe el reporte de horas extra, EL SISTEMA DEBE contabilizar como horas suplementarias únicamente las solicitudes Aprobadas que estén respaldadas por las marcaciones del empleado. Must Have (Obligatorio)
  • RF-019 - Marcaciones Incompletas: CUANDO un empleado tenga una sola marcación en el día, EL SISTEMA DEBE marcar el registro como incompleto y señalarlo a Recursos Humanos. Must Have (Obligatorio)
  • RF-020 - Filtros de Reporte: CUANDO el usuario aplique filtros por empleado, departamento o rango de fechas, EL SISTEMA DEBE actualizar el reporte con los resultados. Should Have (Deseable)
  • RF-021 - Detalle de Marcaciones: CUANDO el usuario seleccione un empleado, EL SISTEMA DEBE mostrar todas sus marcaciones con fecha y hora. Must Have (Obligatorio)
  • RF-022 - Bitácora de Importaciones: CUANDO finalice una importación, EL SISTEMA DEBE registrar fecha, usuario, tipo de archivo, resultado y cantidad de registros importados. Should Have (Deseable)
  • RF-023 - Importación de Permisos y Ausencias: CUANDO el usuario cargue el reporte de permisos y ausencias exportado de Z-BioTime, EL SISTEMA DEBE importar las solicitudes con su estado de aprobación. Must Have (Obligatorio)
  • RF-024 - Importación de Horas Extra: CUANDO el usuario cargue el reporte de horas extra exportado de Z-BioTime, EL SISTEMA DEBE importar las solicitudes con su estado de aprobación. Must Have (Obligatorio)
  • RF-025 - Actualización de Estado de Solicitudes: CUANDO un archivo de permisos u horas extra incluya solicitudes ya importadas con un estado distinto, EL SISTEMA DEBE actualizar el estado de la solicitud y recalcular los indicadores afectados. Must Have (Obligatorio)
  • RF-026 - Consulta de Vacaciones: CUANDO el usuario consulte un día o un período, EL SISTEMA DEBE mostrar qué empleados están de vacaciones. Should Have (Deseable)
  • RF-027 - Headcount por Área: CUANDO el usuario consulte los indicadores, EL SISTEMA DEBE mostrar el número de empleados (headcount) por área. Should Have (Deseable)
  • RF-028 - Índice de Rotación: CUANDO el usuario consulte los indicadores, EL SISTEMA DEBE calcular el índice de rotación general y por área. Could Have (Opcional)

Requisitos no funcionales

  • RNF-001 - Confidencialidad de Datos: EL SISTEMA DEBE almacenar las contraseñas de los usuarios cifradas (hash) y permitir el acceso a la información de nómina solo a usuarios autenticados. Must Have (Obligatorio)
  • RNF-002 - Procesamiento de Marcaciones: EL SISTEMA DEBE procesar 10 000 marcaciones en menos de 10 segundos. Should Have (Deseable)
  • RNF-003 - Actualidad de los Datos: EL SISTEMA DEBE permitir cargas diarias de archivos, de modo que la información tenga como máximo un día de desfase respecto a las marcaciones. Must Have (Obligatorio)
  • RNF-004 - Identidad Visual: EL SISTEMA DEBE usar los colores corporativos de NetPlus en su interfaz y sus gráficos. Should Have (Deseable)

Restricciones

  • REST-001 - Fuente de Datos: EL SISTEMA DEBE obtener las marcaciones, los permisos y las horas extra únicamente de los reportes Excel exportados desde Z-BioTime, sin alterar los valores del archivo original. Must Have (Obligatorio)
  • REST-002 - Plataforma Web: EL SISTEMA DEBE ser una aplicación web que funcione en Chrome, Edge y Firefox. Must Have (Obligatorio)
  • REST-003 - Datos de Muestra Anonimizados: EL EQUIPO DE DESARROLLO DEBE trabajar con archivos de muestra anonimizados, sin nombres de empleados ni datos sensibles. Must Have (Obligatorio)
