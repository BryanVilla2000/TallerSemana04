Tecnologías a utilizar

Dashboard de Nómina NetPlus

Inicio Requisitos Tecnologías Figma

Frontend

  • React con Vite: para construir las pantallas del sistema.
  • React Router: para moverse entre las páginas (inicio, reportes, configuraciones).
  • Axios: para comunicar el frontend con el backend.
  • Bootstrap: para el diseño y que se adapte a escritorio y tablet.
  • Recharts: para los gráficos de asistencia y puntualidad.

Backend

  • Node.js con Express: servidor y API del sistema.
  • Multer y xlsx: para subir y leer el Excel de marcaciones.
  • bcrypt y JSON Web Token: para el login, las contraseñas cifradas y las sesiones.
  • dotenv y cors: variables secretas y comunicación con el frontend.
  • dayjs: para calcular horas, atrasos y fechas.

Base de datos

  • PostgreSQL: guarda usuarios, marcaciones, horarios, feriados y la bitácora de importaciones.

Herramientas

  • Git y GitHub: control de versiones y trabajo en equipo.
  • VS Code: editor de código.
  • Postman: para probar la API.
