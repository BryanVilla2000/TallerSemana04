Propuesta del proyecto

¿De qué trata el proyecto?

NetPlus necesita controlar las marcaciones de su personal. Hoy esa información sale del sistema Z-BioTime y se revisa de forma manual.

Nuestra propuesta es una aplicación web donde se importa el reporte de marcaciones en Excel y el sistema calcula las horas trabajadas, los atrasos y las faltas, y muestra reportes e indicadores de asistencia y puntualidad.

¿Por qué importar un Excel?

NetPlus nos confirmó que no cuenta con API ni SDK de Z-BioTime, por eso la fuente de datos será el reporte de marcaciones exportado desde el sistema.
